# Context Management 
## Slash commands
- `/context`: context window details
- `/compact`: compacts the context
- `/clear` : clear the context, for a fresh start
## Tips
- Use `/compact` when you need to continue working on a topic after a long conversation.
- Use `/clear` , when you want to start working on a new feature.
- MCP servers may take unnecessary context, kindly turn off the unused mcp servers.
- Recurrent info need to be stored in `Claude.md`.

### Sub-agents
- Run in parallel with main agent and has a different context window of it's own.
- Used for specific tasks like code review,testing,etc.
