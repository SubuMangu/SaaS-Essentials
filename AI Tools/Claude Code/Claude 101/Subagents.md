## Subagents
- Used for specialized tasks
- Each subagent has their own context window, at the end it provides summary to the main agent. Helps in better context window management.

## Built in subagents
1. **General Purpose Subagents:** Used for multistep task that requires both exploration and action.
2. **Explore Subagents:** Fast searching of codebases.
3. **Plan Subagent:** Used during plan mode , for research and analysins of your codebase before presenting a plan
